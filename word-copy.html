两种后端说明 / 本地助手怎么用

① 本地助手（推荐，免授权，用真实文件夹路径）：双击仓库里的 word-copy.bat 最省事 —— 它会自动启动助手并打开本页；也可以手动运行 tools\word-copy-server.ps1，然后访问 http://127.0.0.1:8765/（或直接双击本页， 页面会自动探测本机助手）。两种打开方式都不用授权任何文件夹：两个默认目录已经填好，直接点「文件复制」。 助手只监听 127.0.0.1，只做「递归列出源目录及子目录里的 Word 文件」和 「按生成日期把它们复制进目标目录」两件事：归档时最多只多一层 年-月-日 文件夹， 不照搬源目录结构、不删除任何东西，关掉窗口即停止。

② 浏览器授权（无需助手）：点「授权源目录 / 授权目标目录」，在系统选择器里授权两个文件夹， 页面用 File System Access API 逐份复制。限制：必须由你亲手授权，输入框里手打的路径无法被网页读取。

③ 兜底：两者都不可用时，点「生成复制命令」，把命令粘贴到 PowerShell 执行。 同样递归、同样只拷 Word、同样按勾选决定归档或平铺；区别是一条命令没法给同名文件改名， 同一份日期文件夹里的同名 Word 文件会互相覆盖 —— 要保留两份请用助手或授权模式。

文件没有修改就不重复写入：目标里已有同名且内容没再改过的文件直接跳过，也不会碰它的写入时间。 助手模式按「大小相同 + 修改时间相同」判定；浏览器授权模式写入后目标时间会变成「刚才」， 所以改用「大小相同 + 目标不比源旧」。取消「同名则覆盖」后同名文件一律跳过。

点授权按钮直接打开默认目录：已经授权过的目录会被记住（存在浏览器 IndexedDB 里）， 以后再点同一个按钮直接打开默认目录（就是输入框里那个路径，或它下面的子目录），不再弹选择器。 第一次点还是会弹系统选择器 —— 浏览器安全上不允许网页凭空按路径打开文件夹，必须亲手授权一次； 页面会同时把默认目录和「双击 word-copy.bat 免授权直达」的做法标出来，选完目录界面立刻更新， 不会卡在存储上。记住的目录被移动或权限被收回，会自动退回系统选择器重选一次。想主动换目录：按住 Shift 再点按钮， 或点记忆条上的「清除记忆」。

建不出日期文件夹时怎么排查：报错会点名是哪个文件夹。 「同名位置已经是一个文件」= 目标目录里有个文件正好叫 2026-11-13 这样，改名或挪走即可； 「请确认目标目录可写」= 目录只读或被占用，换一个可写目录或加上权限； 「只给了只读权限」= 授权目标目录时没允许写入，重新授权或改用本机助手； 「本机助手是旧版本」= 端口上跑着改动前启动的助手，关掉窗口重新双击 word-copy.bat。

本页零依赖、零构建，可离线双击打开。自检：?selftest=1。 指定助手地址：?helper=…；自动执行：?src=…&dst=…&autocopy=1。
