两种后端说明 / 本地助手怎么用

① 本地助手（推荐，免授权，用真实文件夹路径）：双击仓库里的 word-copy.bat 最省事 —— 它会自动启动助手并打开本页；也可以手动运行 tools\word-copy-server.ps1，然后访问 http://127.0.0.1:8765/（或直接双击本页， 页面会自动探测本机助手）。两种打开方式都不用授权任何文件夹：两个默认目录已经填好，直接点「文件复制」。 助手只监听 127.0.0.1，只做「递归列出源目录及子目录里的 Word 文件」和 「把文件平铺复制到目标目录」两件事：不建子目录、不删除任何东西，关掉窗口即停止。

② 浏览器授权（无需助手）：点「授权源目录 / 授权目标目录」，在系统选择器里授权两个文件夹， 页面用 File System Access API 逐份复制。限制：必须由你亲手授权，输入框里手打的路径无法被网页读取。

③ 兜底：两者都不可用时，点「生成复制命令」，把命令粘贴到 PowerShell 执行。 同样递归、同样只拷 Word、同样平铺；区别是一条命令没法给同名文件改名， 不同子目录里的同名 Word 文件会互相覆盖 —— 要保留两份请用助手或授权模式。

文件没有修改就不重复写入：目标里已有同名且内容没再改过的文件直接跳过，也不会碰它的写入时间。 助手模式按「大小相同 + 修改时间相同」判定；浏览器授权模式写入后目标时间会变成「刚才」， 所以改用「大小相同 + 目标不比源旧」。取消「同名则覆盖」后同名文件一律跳过。

点授权按钮会自动跳到对应目录：第一次授权后目录会被记住（存在浏览器 IndexedDB）， 以后再点同一个按钮直接跳回上次那个目录，不再弹选择器；输入框里填的是它下面的子目录时还会自动进到那一层。 记住的目录被移动或权限被收回，会自动退回系统选择器重选一次。想主动换目录：按住 Shift 再点按钮， 或点记忆条上的「清除记忆」。

本页零依赖、零构建，可离线双击打开。自检：?selftest=1。 指定助手地址：?helper=…；自动执行：?src=…&dst=…&autocopy=1。
